# 接线表

主控：AT89C52 / STC89C52，12MHz 晶振，5V 供电。

## 1. 最小系统

| 单片机引脚 | 接到 | 说明 |
|---|---|---|
| XTAL1 / XTAL2 | 12MHz 晶振两端 | 各配 30pF 瓷片电容到 GND |
| RST | 复位电路 | 10μF 电容 + 10kΩ 电阻 + 复位按键，上电复位 + 手动复位 |
| EA | 5V | 使用片内程序存储器 |
| VCC / GND | 5V / GND | 就近加 0.1μF 去耦电容 |
| P0.0~P0.7 | 10kΩ 排阻 → 5V | P0 内部无上拉，必须外接 |

## 2. 温度采集（DS18B20）

| DS18B20 | 接到 | 说明 |
|---|---|---|
| VDD | 5V | 外部供电方式 |
| GND | GND | — |
| DQ | P1.5 | **必须**外接 4.7kΩ 上拉到 5V，否则读不到数据 |

## 3. 烟雾采集（MQ-2 + ADC0832）

| 器件引脚 | 接到 | 说明 |
|---|---|---|
| MQ-2 VCC | 5V | 加热丝供电，上电需预热 2~3 分钟 |
| MQ-2 GND | GND | — |
| MQ-2 AO | ADC0832 CH0 | 模拟输出 |
| ADC0832 CS | P2.3 | 片选 |
| ADC0832 CLK | P2.0 | 时钟（软件模拟） |
| ADC0832 DI/DO | P2.1 | 数据（本工程只用 DO 读） |
| ADC0832 VCC/GND | 5V / GND | — |

> 电平判读：`dengji = ad0832read(1,0) * 10 / 250`，即 0~250 的 AD 值映射为 0~9 级。

## 4. 显示（4 位共阴数码管）

| 数码管 | 接到 | 说明 |
|---|---|---|
| 段选 a~g、dp | P0.0~P0.7 | 共阴，段码高电平点亮 |
| 位选 1~4 | P2.4~P2.7 | 低电平选通，动态扫描 |

## 5. 按键与报警

| 功能 | 引脚 | 说明 |
|---|---|---|
| 设置键 | P1.0 | 按下拉低，进入/退出阈值设置 |
| 加键 | P1.1 | 阈值 +1 |
| 减键 | P1.2 | 阈值 -1 |
| 紧急报警键 | P1.3 | 手动触发/取消报警 |
| 蜂鸣器 | P3.6 | 经 NPN 三极管（如 S8050）基极限流 1kΩ 驱动 |
| 温度报警灯（红） | P1.6 | 串 1kΩ 限流 |
| 烟雾报警灯（黄） | P1.7 | 串 1kΩ 限流 |

> 引脚以实际工程 `main.c` 顶部的 `sbit` 定义为准；不同批次套件的位选可能改到 P2 其他脚，接线前先对一遍代码。

## 6. 上电检查顺序

1. 目测：芯片方向、电解电容极性、二极管方向
2. 不通电，万用表通断档测 VCC-GND 是否短路
3. 通电测 VCC = 5V±0.5V
4. 测晶振两端对地电压（约 2V 左右，起振）
5. 测 RST 上电瞬间为高、稳定后为低
6. 最后插传感器与显示模块
