# 功能测试记录

测试环境：AT89C52 @12MHz，5V 供电，室温 22℃。

| 编号 | 测试项 | 操作 | 预期 | 实测 | 结论 |
|---|---|---|---|---|---|
| T01 | 上电自检 | 通电 | 蜂鸣器响一声，数码管显示初始值 | 一致 | 通过 |
| T02 | 温度采集 | 手指握住 DS18B20 | 数值上升，约 1℃/s | 数值上升正常 | 通过 |
| T03 | 温度精度 | 与电子温度计对比 5 次 | 误差 ≤ ±1℃ | 最大偏差 0.8℃ | 通过 |
| T04 | 烟雾采集 | 打火机放气靠近传感器（不点火） | 等级由 0~1 升至 6 以上 | 3 秒内升至 7 | 通过 |
| T05 | 烟雾报警 | 等级超过设定值 4 | 蜂鸣器滴滴 + 黄灯闪 | 一致，响应 <1s | 通过 |
| T06 | 温度报警 | 电烙铁靠近 DS18B20 升温至 34℃（阈值 33℃） | 蜂鸣器 + 红灯 | 一致 | 通过 |
| T07 | 阈值设置 | 按设置键，用加减键改到 30℃ | 显示切换、数值可调 | 一致 | 通过 |
| T08 | 自动退出 | 设置状态静置 30s | 自动保存并返回主界面 | 一致 | 通过 |
| T09 | 掉电保存 | 改阈值后断电 10s 再上电 | 阈值保持不变 | 一致 | 通过 |
| T10 | 手动报警 | 按紧急报警键 | 立即声光报警，再按取消 | 一致 | 通过 |
| T11 | 连续运行 | 通电 72h | 不死机、不误报 | 无异常 | 通过 |

## 结论

- 温度测量误差 ≤ ±1℃，满足设计要求
- 烟雾等级为定性显示，不做定量标定（MQ-2 本身选择性差，这是它的固有局限，不是程序问题）
- 误报率在加入预热延时 + 中位值平均滤波后明显下降

## 已知不足

1. MQ-2 无法区分气体种类，只能给「浓度等级」，不能当气体报警器用
2. 无湿度采集
3. 无联网能力（已在 `wifi-fire-alarm` 仓库中补上）
4. 数码管显示信息有限，参数名靠位置约定，新手不容易看懂
