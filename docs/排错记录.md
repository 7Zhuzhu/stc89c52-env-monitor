# 排错记录

实训与课程设计期间真实踩过的坑。每条都按「现象 → 可能原因 → 怎么验证 → 实际原因」。

---

## 1. DS18B20 读数恒为 85℃

- **现象**：数码管温度位一直显示 85，换传感器还是 85。
- **可能原因**：①初始化时序不对 ②没有等转换完成就去读 ③上拉电阻没接
- **验证**：85℃ 是 DS18B20 上电默认值，说明读到的是「未转换」的寄存器
- **实际原因**：读之前少了一次 `write_18b20(0x44)` 启动转换 + 延时等待
- **处理**：先发 `0xCC`（跳过 ROM）→ `0x44`（启动转换）→ 延时 → `0xCC` → `0xBE`（读暂存器）
- **经验**：单总线对时序敏感，延时函数不能随便改；改了延时就要重新验证

## 2. MQ-2 上电就报警，误报严重

- **现象**：刚上电烟雾等级就跳到阈值以上，蜂鸣器一直响，过几分钟又正常。
- **可能原因**：①传感器未预热 ②电源不稳 ③阈值设太低
- **验证**：观察 3 分钟，等级从 8 慢慢掉到 1，说明是预热过程
- **实际原因**：MQ-2 加热丝冷态电阻小、电流大，输出偏高
- **处理**：上电后延时 2~3 分钟再进入采集；采集值做中位值平均滤波（去掉最大最小再平均）
- **经验**：气敏传感器不要「上电即用」，这是硬件特性，不是程序 bug

## 3. 数码管显示闪烁、亮度不均

- **现象**：数字一闪一闪，四位亮度不一致。
- **可能原因**：①扫描频率太低 ②在主循环里扫描，被其他函数阻塞
- **处理**：把扫描放进定时器中断（约 1~2ms 一次），主循环只负责算数据
- **经验**：动态扫描必须和主循环解耦，否则任何延时函数都会让显示抖

## 4. 按一次键，阈值跳好几下

- **现象**：按一下加键，数值 +3。
- **可能原因**：机械按键抖动，10~20ms 内电平多次跳变
- **处理**：检测到低电平后延时 10~20ms 再判一次，或连续两次采样一致才认
- **经验**：所有按键都要消抖，别指望「手快就不会抖」

## 5. 阈值改完，重新上电又变回默认

- **现象**：设置 33℃ 后断电，再上电又回到 50℃。
- **可能原因**：①没写 EEPROM ②写之前没擦除扇区 ③写的是 RAM 变量
- **处理**：`SectorErase(0x2000)` → 逐字节 `byte_write` → 上电 `byte_read` 读回；用标志位 `a_a` 判断是否首次上电
- **经验**：STC89C52 的 EEPROM 按扇区擦除，擦一次整个 512B 都没了，所以要把相关参数写在同一扇区

## 6. 买来的半成品板只能点亮 LED，功能全无

- **现象**：通电后只有一个 LED 亮，按键、显示、报警都不响应。
- **排查过程**：
  1. 量 VCC：5V 正常
  2. 量晶振：一端有电压但不起振 → 怀疑晶振或电容
  3. 对照原理图逐脚核对芯片方向与跳线 → 发现主控芯片方向装反 + 两处跳线帽缺失
  4. 更正后仍只有 LED 亮，读不到传感器数据
- **结论**：板子本身是缺陷件（丝印与原理图不符），不是接线问题
- **处理**：及时联系卖家换货，没有继续在坏板上浪费时间
- **经验**：**先判「是不是硬件坏了」再改代码**。判据是「换一块好板，同样的程序能不能跑」——这一条能省掉几天的无效调试

## 7. 程序下载成功但不运行

- **现象**：STC-ISP 提示下载成功，断电重上电没反应。
- **可能原因**：①没冷启动（要断电再上电）②EA 脚没接高 ③晶振没起振
- **处理**：确认 EA 接 5V、下载后彻底断电再上电
- **经验**：STC 系列必须冷启动才进下载模式，热复位不算

---

## 通用排查顺序（可复用）

1. **电源**：先量 VCC 与 GND，再谈其他
2. **时钟**：晶振起振没有
3. **复位**：RST 电平对不对
4. **通信线**：通断、上拉、方向
5. **换件法**：怀疑哪个模块，换一个已知好的上去
6. **仿真对照**：Proteus 里用同一个 hex 跑一遍，仿真正常而实物不正常 → 硬件问题；仿真也不正常 → 程序问题

这一条 6 步在我后面的项目里一直用，能挡掉大部分「不知道从哪下手」的情况。
